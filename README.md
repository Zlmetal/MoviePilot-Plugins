# 115海搜转存

从[海搜](https://haisou.cc/)搜索115网盘资源并自动转存到115网盘。

## 功能

- 从海搜网站搜索115网盘资源
- 搜索结果包含标题、文件大小、文件数、提取码
- 一键转存到115网盘
- 支持MP消息交互（微信、Telegram等）
- 支持AI智能体调用搜索

## 前置依赖

**必须先安装并启用 [115网盘STRM助手](https://github.com/DDSRem-Dev/MoviePilot-Plugins) (P115StrmHelper) 插件**

本插件的转存功能依赖 P115StrmHelper 插件实现，请确保：
1. 已安装 P115StrmHelper 插件
2. 已配置115网盘账号和转存目录
3. P115StrmHelper 插件处于启用状态

## 安装

在 MoviePilot 插件市场中添加第三方插件源：
```
https://github.com/Zlmetal/MoviePilot-Plugins
```

搜索"115海搜转存"并安装。

## 使用方法

### 搜索资源
```
/hs 电影名
```
例如：`/hs 绿液惊魂 2026`

### 选择并转存
```
/hs select 序号
```
例如：`/hs select 1`（转存搜索结果中的第1个资源）

### 智能体调用
在支持AI智能体的渠道中，直接发送影视名称，智能体会自动调用海搜搜索115资源。

## 配置

| 配置项 | 说明 |
|--------|------|
| 启用插件 | 开启/关闭插件 |
| 海搜Cookie | 登录haisou.cc后从浏览器获取（留空也可用，有每日次数限制） |

### 获取Cookie（可选）

1. 浏览器登录 https://haisou.cc
2. 按 F12 打开开发者工具
3. 切换到 Network 标签
4. 刷新页面，点击任意请求
5. 在 Request Headers 中复制完整的 Cookie 值

VIP用户配置Cookie后可享受无限制搜索次数。

# 动态企微QQ通知补丁

让 [动态企微可信IP](https://github.com/jxxghp/MoviePilot-Plugins)（`DynamicWeChat`）的通知走 **QQ Bot**。

## 解决的问题

`DynamicWeChat` 的通知发送器 `MySender` 只认四种通道，按 Token 前缀猜：

- Token 含 `wechat` → 走 MoviePilot 的微信渠道
- 以 `sct` 开头 → ServerChan
- 含 `iyuu` → IYUU
- 其它一律当 PushPlus

**没有 QQ 分支**。所以哪怕 MoviePilot 里 QQ Bot 已经配好了，企微 cookie 失效通知、登录二维码、换 IP 结果这些消息也推不到 QQ。

## 怎么做的

不修改 `DynamicWeChat` 的任何文件，只在本插件加载时，于**内存中**替换
`app.plugins.dynamicwechat.helper.MySender._send_v2_wechat`，
把 `channel=MessageChannel.Wechat` 换成 `MessageChannel.QQ`，其余参数原样透传。

- 插件加载顺序 `plugin_order = 46`，排在 `DynamicWeChat`(47) 之前，保证先打补丁再初始化
- 监听 `PluginReload` 事件，`DynamicWeChat` 重载/升级后自动重新打补丁
- 关闭本插件即还原原始方法
- 目标插件未安装、或方法名变更时会打警告日志，不影响 MoviePilot 启动

## 前置条件

1. MoviePilot 版本 ≥ 2.15（`MessageChannel.QQ` 与 `NotificationType.Plugin` 已存在）
2. 已安装并启用 `动态企微可信IP`（DynamicWeChat）
3. MoviePilot **通知设置 → QQ** 已配置并启用，且**消息类型勾选了「插件」**
4. `DynamicWeChat` 配置里的**「通知方式」Token 必须填一个含 `wechat` 字样的值**（比如 `wechat`），这是触发 `_send_v2_wechat` 分支的条件；逗号后那段会被当作 userid，可以留空

## 配置

| 配置项 | 说明 |
|--------|------|
| 启用插件 | 开启后立即接管通知通道 |
| 通知渠道 | `QQ`（默认）或 `微信`（还原原版行为） |

## 自检

启用后打开插件详情页，会显示「补丁状态：已接管 → QQ」。
也可以调用 `/api/v1/plugin/DynamicWeChatQQPatch/status` 查看补丁状态，
用 `/test` 直接发一条测试通知验证通道。

## 许可证

GPL-3.0

# 网盘订阅智能下载补丁

给 [网盘订阅助手](https://github.com/jxxghp/MoviePilot-Plugins)（`CloudSubscribe`）补一条下载策略。

## 解决的问题

PT 站新片首发往往只有 1080P WEB-DL 甚至 HDTV，几小时后网盘渠道就出现 4K 原盘、REMUX 这类更好的版本。
但订阅一有 PT 资源就立刻下载，好版本来了也已经下完，或者已经在做种。

## 怎么做的

1. PT 资源即将下载时先拦下（不建种、不占下载器），给该订阅开一个等待窗口；
2. 窗口内定时搜索网盘渠道，按画质/来源/字幕/音轨打分，记录最优候选；
3. 窗口到期时：
   - 找到合格网盘资源 → 交给「网盘订阅助手」提交转存；
   - 没找到 → 放行，并重新触发该订阅的 PT 搜索。

不修改原插件任何文件，只挂事件与独立定时服务。

## 候选优先级

同一轮里按 **无需解锁的网盘资源 > 需解锁的网盘资源 > 短效第三方分享 > PT 资源** 排序：

- 层级压过分数：只要窗口内存在任何网盘候选，就不会放行 PT；
- 档位只看「能不能直接拿到链接」：网盘分享直链＝0，需积分解锁（need_unlock）或免费待领取（need_access）＝1，短效第三方分享＝1.9，磁力/ed2k 这类要下载器去拖的＝2；
- 需积分解锁的资源（如 Dian115）先按标题/描述参与比价，**只有排到第一时才会真正花积分解锁**，不会为了比价白花积分；
- Dian115 上「免积分但需要点一次领取」的资源（need_access）同样进候选；排到第一时补丁会先向渠道领取真实链接，再把候选交给网盘订阅助手（原插件的提交接口只认直链或 need_unlock，免费资源会被漏掉）；
- 支持排除无中文字幕、杜比视界、非国语、低于指定分辨率的候选；
- 第一名解锁失败会自动顺位试下一名，全失败则保留窗口等下次巡检。

## 分享链接有效性与寿命

pansou 这类聚合源给的都是别人的第三方分享，常在等待期内被取消或删除。
等到窗口到期才提交，同步链只会记一句「分享链接无效」然后整批失败——白等一天。

补丁的做法分两层：

**一、先查死活**

- 巡检时向网盘端查一次链接状态，已失效的直接剔除，不占 `best` / `ranked` 名额；
- 提交前再确认一遍，死链就顺位到下一个候选，不交给同步链；
- 已记录的最优候选中途失效时，会被新搜到的候选替换（哪怕分数更低）；
- 同一链接 6 小时内只校验一次，单轮最多校验 5 个，避免触发 115 的 QPS 风控；
- 需解锁 / 免费待领取的候选没有直链，不做这一层校验。

**二、再算寿命**

死链接能当场查到，但「现在还活着、几小时后可能被删」的链接查不出来。
所以排序时把**短效第三方分享**（`pansou` 这类聚合源）从「网盘直链」降一档：

```
无需解锁网盘(0) > 需解锁网盘(1) > 短效第三方分享(1.9) > PT(2)
```

宁可花一次积分解锁个稳的，也别等到期才发现链接早被人删了。
这条可以用「优先稳定链接」开关关掉，关掉后短效直链恢复普通直链、直接排第一。

日志里会看到 `候选链接已失效（已取消）：...`、`第 N 名链接已失效，顺位下一个`，
以及页面上短效候选标注的「网盘直链（短效分享）」。

## 配置

| 配置项 | 说明 |
|--------|------|
| 启用插件 | 关闭后完全不干预，PT 照常直下 |
| 干跑模式 | 只记决策、不真拦不真提交 |
| 等待小时数 | 窗口长度，默认 24 |
| 巡检间隔 | 多久搜一次网盘，默认 60 分钟 |
| 到期策略 | `best_at_expiry`（到期才交）/ `immediate`（一有候选就交） |
| 排除无中文字幕 | 默认开 |
| 排除杜比视界 | 默认关 |
| 必须国语 | 默认关 |
| 最低分辨率 | 不限 / 1080P / 4K |
| 允许花积分解锁候选 | 默认开；关闭后未解锁资源只参与比价、永不被选 |
| 单次解锁积分上限 | 不限 / 10 / 30 / 50 / 100，超出的需解锁资源直接跳过 |
| 优先稳定链接 | 默认开；开启后短效第三方分享（pansou 等）排在需解锁网盘之后 |

## 前置条件

1. 已安装并启用「网盘订阅助手」（`CloudSubscribe`）
2. 该订阅已被「网盘订阅助手」纳管（沿用它的 include/exclude 名单）

## 排查

日志前缀 `【网盘订阅智能下载补丁】`。
也可调 `/api/v1/plugin/CloudSubscribePatch/status` 看当前窗口与最优候选，
`/api/v1/plugin/CloudSubscribePatch/check_now` 手动触发一次巡检。
